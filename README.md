# 最近均值报价博弈：单次报价蒙特卡洛案例

> A reproducible single-bid analysis for a large-population nearest-mean contest.

本项目研究一个具体问题：当中标条件是“报价最接近所有报价的均值”时，如何把有限事实、主观先验和蒙特卡洛模拟组合成一条可复核的单次报价路线。

> [!IMPORTANT]
> 活动没有公开网球拍报价分布。下列结果依赖一组辅助先验，不是从 LKs 粉丝画像估计出的客观真值，也不保证中标。

## 结论

在仓库保存的辅助先验路线下，模型内部精确到分的最终报价是：

```text
164.74 元
```

选择它有两个直接理由：

1. 四个报价组件的加权均值为 `164.742`，四舍五入后是 `164.74`。
2. 对 163.50–165.50 元逐分模拟后，用 15 个相邻分币平滑蒙特卡洛噪声，平滑目标函数也在 `164.74` 达到最大值。

`164.65–164.85` 属于近优平台；`165.00` 虽接近均值，但整数同价拥挤使模拟中标率从附近非整数价的约 `0.36%` 降至约 `0.0017%`。因此 `164.74` 是一个清晰的操作选择，不应被理解为现实均值已经精确测到分。

## 164.74 是怎样算出的

原始辅助先验是：网球兴趣者占 `35%`、使用 AI 辅助者占 `20%`。模型另设“较高报价组使用共同信号的倾向是总体的 1.30 倍”，于是四个联合权重为：

```text
D = 0.35 × (0.20 × 1.30) = 0.091
C = 0.20 − 0.091          = 0.109
B = 0.35 − 0.091          = 0.259
A = 1 − B − C − D         = 0.541
```

为避免把这些先验误写成真实人口分类，代码把它们作为四个潜在报价组件使用：

|组件|权重|报价中心（元）|模型含义|
|---|---:|---:|---|
|A|0.541|148|较低中心、独立信号|
|B|0.259|196|较高中心、独立信号|
|C|0.109|165|较低中心、共同信号|
|D|0.091|175|较高中心、共同信号|

因此理论均值是：

```text
0.541×148 + 0.259×196 + 0.109×165 + 0.091×175
= 164.742 元
```

随后对每个分币报价 `b` 计算：

```text
没有更近对手的概率 × 并列时的获胜份额 × 正消费者剩余
```

默认细网格使用 `N=25,000`、180,000 次模拟；指定报价另用 600,000 次模拟，逐人生成的一亿条对手报价用于数量级校验。原始逐分最大值会受蒙特卡洛噪声影响，所以最终规则采用 15 分宽的局部平均；这一步把“偶然最高的一分钱”和“稳定中心”区分开来。

完整推导、概率比较与敏感性分析见 [完整报告](reports/full-analysis.md)。

## 哪些信息真正进入了模型

- 官方规则：最接近该物品全部报价均值者中标。
- 截止日当天快照：全活动 194,411 人提交，网球拍有 12,281 人报价。
- 商品信息：95 新、270g、100 平方英寸，附 3 个 Wilson 网球。
- 价格锚：同款或近似款公开价格约 1,420–1,584 元，以及活动中“此前大多为原价一折或更低”的提示。
- 辅助先验与情景参数：35%、20%、四个报价中心、离散度、整数堆积和共同信号相关性。

没有可复核数据支持的 LKs 用户画像不会进入模型。真正缺失、且最有价值的数据是该物品的匿名报价直方图、往期同类物品均值和明确的并列规则。

## 敏感性边界

改变较高报价组件占比、两个报价中心或一折锚响应时，模型最优点可移动到约 `158.29–171.18` 元；只改变共同信号参数时，最优点约为 `164.57–164.89` 元。这说明参数风险远大于相邻几分钱的差异。

## 复现

需要 Python 3.10 或更高版本：

```bash
python -m venv .venv
# Windows PowerShell
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt

# 快速检查，结果写入临时目录
python src/lks_tennis_mc.py --quick --section main --output-dir work/quick-check
```

完整运行：

```bash
python src/lks_tennis_mc.py --section all --output-dir data/reproduced-main
python src/lks_tennis_mc.py --section direct --output-dir data/reproduced-direct
python scripts/create_figure.py
```

参数可通过 `--upper-strategy-share`、`--shared-signal-share` 和 `--anchor-scale` 覆盖。详见 [复现说明](docs/reproducibility.md)。
